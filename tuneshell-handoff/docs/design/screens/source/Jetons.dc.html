Règles d'implémentation

  1. Polices embarquées (assets/fonts, OFL). Ne pas laisser google_fonts les télécharger à l'exécution : ce serait un appel réseau, contraire à « sans télémétrie ».
  2. Couleurs dynamiques en option : réglage « Couleurs du fond d'écran » (dynamic_color). Par défaut, le ColorScheme TuneShell. TsColors reste fixe dans les deux cas.
  3. Bandeaux dans le flux : CustomScrollView → SliverToBoxAdapter(StatusBanner) puis SliverFixedExtentList(itemExtent: 64). Jamais d'Overlay.
  4. Mise en page adaptative : largeur < 600 → NavigationBar ; 600–839 → NavigationRail ; ≥ 840 → rail + panneau lecteur. Le paysage du téléphone (≈ 915 dp) tombe dans « étendu ».
  5. Zones tactiles : MaterialTapTargetSize.padded partout, IconButton 48 minimum.
  6. Texte agrandi : tester à 200 % ; les lignes de 64 passent alors à une hauteur variable (désactiver itemExtent au-delà de 1,3×).
